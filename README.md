What is C#?
C# is a modern, general-purpose, object-oriented programming language developed by Microsoft. It is widely used to develop various types of applications, including:
  Windows Desktop Applications
  Web Applications and Web APIs
  Database Applications
  Games (using Unity)
  Cloud and Business Applications

What is .NET Framework?
.NET Framework is a collection of classes and libraries used to build and run applications on Windows. C# fully supports the .NET platform. The acronym .NET stands for Network Enabled Technology.

2. Visual Studio Environment & GUI Design

Key Visual Studio Windows
  Designer Window: Used to design the user interface (GUI) of the application.
  Solution Explorer: Manages and displays all files, references, and resources in the project.
  Toolbox: Contains all the controls (buttons, labels, textboxes, etc.) that can be added to a form.
  Properties Window: Used to view and change the properties (appearance and behavior) of selected controls.
    Left column: Property Name
    Right column: Property Value

Working with Controls on a Form
  Sizing & Resizing: Use the Bounding Box and Sizing Handles around a control to change its size.
  Moving: Click and drag the control to reposition it on the form.
  Deleting: Select the control and press the Delete key.
  Tooltips: Small pop-up descriptions that appear when hovering over items in the toolbar or toolbox.

3. C# Code Structure (Code Organization)

C# code is primarily organized into three levels:
1. Namespace: A container that holds classes.
2. Class: A container that holds methods.
3. Method: A group of one or more programming statements.

Project Files
  Source Code File: A file containing program code.
  Program.cs: Contains the application start-up code executed when the application runs.

4. Objects, Classes, and GUI Controls

  Object: A program component containing both data and operations.
  Class: A template or blueprint that defines what an object will be.
  Properties: Data stored inside an object (such as color, size, or text).
  Methods: Actions or operations an object can perform.

Controls
  Common Controls: Visible components on a form like Labels, Buttons, and TextBoxes.
  Invisible Objects: Components not visible on the GUI while the app is running, such as Timers or OpenFileDialog.

5. Rules for Naming Controls (Identifiers)

When setting the Name property of a control, the following rules must be followed:
  The first character must be a letter (A-Z, a-z) or an underscore (_).
  The name cannot start with a digit.
  C# reserved keywords cannot be used.
  Spaces are not allowed within the name.

6. Event-Driven Programming and Label Control

Event-Driven Architecture
  Event: User actions such as clicking the mouse, pressing a key, or moving the mouse.
  Event-Driven: GUI applications respond to events that occur while the application is running.
  Default Event Handler: Generated by double-clicking a control in the designer to write its event handler code.
  Message Box: Used to display output or messages to the user (functions like a print statement).

Label Control and Properties
The Label control is used to display text on a form or show program output that the user cannot edit directly.

Key Properties:
  Text: Gets or sets the text displayed on the Label.
  Name: The identifier or control name used in code.
  Font: Sets font style, size, and font name.
  BorderStyle: Sets the border around the label (Values: None, FixedSingle, Fixed3D).
  AutoSize: Controls whether the label automatically resizes (True or False).
  TextAlign: Sets the alignment of the text inside the label.
